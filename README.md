# poseidon

Outils perso pour le TCG de [Poseidon Scans](https://poseidon-scans.net/jeu).

## Contenu

- `poseidon-alertes/` — extension Chrome « Poseidon – Alertes Marché » : surveille les ventes à prix fixe et affiche une notification Windows.
  Installation : `chrome://extensions` → Mode développeur → « Charger l'extension non empaquetée » → choisir ce dossier.
