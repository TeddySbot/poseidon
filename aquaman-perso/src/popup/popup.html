    Mises à jour

    Celestial est disponible.

    Pour mettre à jour en un clic, fais une seule fois : double-clic sur installer-mises-a-jour.bat dans le dossier de l’extension, puis ↻ dans chrome://extensions.

    Sinon : avec Git, git pull ; avec le zip, remplace le contenu du dossier ; puis ↻.

    Toutes les 6 h, l’extension regarde sur GitHub si une version plus récente existe. Rien ne s’installe sans ton clic.
